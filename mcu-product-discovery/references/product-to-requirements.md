# PRD 到 MCU 需求转换

## 输入

```text
产品目标：
目标用户：
使用场景：
竞品结论：
MVP 范围：
非目标：
关键假设：
推荐方案：
```

## 需求拆解

```markdown
| PRD 项 | 需求 ID | MCU/系统影响 | 验收标准 | 验证方式 | 风险 | owner |
| --- | --- | --- | --- | --- | --- | --- |
|  | REQ-FUNC-001 |  |  | unit/integration/HIL/field |  |  |
```

## 需求类型

- 功能需求：状态机、外设、通信、控制逻辑。
- 性能需求：时延、吞吐、采样率、启动时间、功耗。
- 环境需求：温度、湿度、EMC、振动、电源扰动。
- 制造需求：烧录、校准、序列号、工厂测试。
- 维护需求：日志、故障码、远程诊断、升级、回滚。
- 安全合规需求：调试口、密钥、认证、故障安全。

## 出口条件

进入固件或硬件实现前，必须能回答：

- 每条 MVP 功能是否有需求 ID。
- 每条需求是否有验收标准和验证方式。
- 市场/产品假设是否有验证实验。
- 方案选择是否有决策记录和回滚条件。
